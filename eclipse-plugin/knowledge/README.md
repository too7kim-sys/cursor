# UI/UX 지식팩 (폐쇄망 RAG용)

폐쇄망 로컬 모델은 **최신 트렌드/프레임워크 지식이 부족**합니다. 이 폴더의 레퍼런스 문서를
**프로젝트에 넣고 색인**하면, AI가 이 규칙을 참고해 현대적 UI/UX를 구현합니다(파인튜닝 불필요).

## 포함 문서
- [`ui-ux-trends.md`](ui-ux-trends.md) — 현대 UI/UX 원칙(접근성·반응형·디자인 토큰·상태표시·마이크로인터랙션)
- [`nexacro-patterns.md`](nexacro-patterns.md) — 넥사크로(Nexacro) 화면/컴포넌트 패턴·UX
- [`websquare-patterns.md`](websquare-patterns.md) — 웹스퀘어(WebSquare) 화면/컴포넌트 패턴·UX

## 사용법
1. 이 `knowledge/` 폴더(또는 필요한 .md)를 **대상 프로젝트 루트의 `.ollama-assist/knowledge/`** 에 복사
   (또는 사내 디자인 가이드/컴포넌트 카탈로그 .md 를 같은 위치에 추가)
2. 뷰에서 대상 프로젝트 선택 → **[색인]** (지식팩이 함께 색인됨)
3. 사용:
   - 채팅/Agent: **`/ui 회원목록 화면 만들어줘`** → 지식팩 + 프로젝트 기존 패턴을 참고해 구현
   - 넥사크로/웹스퀘어 화면: **`/xfdl <XML>`** 또는 `/ui`
4. **AGENTS.md** 에 사내 UI 규칙(색/간격/네이밍/금지사항)을 적어두면 매 요청에 자동 적용

## 권장
- 사내 **디자인 토큰/컴포넌트 목록**을 `.md` 로 정리해 같은 폴더에 추가하면 정확도가 크게 올라갑니다.
- 모델은 이 문서를 **규칙**으로 활용합니다. 구체적 예시 코드·금지사항을 넣을수록 결과가 좋아집니다.
